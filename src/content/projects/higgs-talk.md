Physics is my hobby. For a talk on one section of a quantum field theory textbook (the Higgs mechanism), I built the slides as a single web page instead of a slide program: animations, keyboard navigation, speaker notes on **N**, and a key (**B**) that pulls up the book's own equation for the current slide. It works on mobile too.
